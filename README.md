# نظام أثير — نظام ERP محاسبي إداري متكامل لإدارة الفنادق

**Atheer Hospitality ERP** — نظام محاسبي إداري من الدرجة المؤسسية (Enterprise-Grade)
لإدارة الفنادق، يعمل بثلاثة أوضاع من قاعدة كود واحدة:

- **محلي (On-Premise):** يعمل 100% بدون إنترنت داخل الفندق.
- **سحابي (SaaS):** متعدد المستأجرين (Multi-Tenant) بنسخ وتحديثات مركزية.
- **هجين (Hybrid):** تشغيل محلي كامل + مزامنة آمنة مع السحابة (تقارير مركزية،
  نسخ احتياطي خارجي، إدارة تراخيص، دعم عن بُعد).

> القاعدة الجوهرية: **كل عملية مالية = قيد محاسبي مزدوج متوازن** (مدين = دائن
> دائماً)، والقيد المرحَّل لا يُعدَّل ولا يُحذف أبداً — التصحيح بقيد عكسي موثق.

## 📦 الوضع الحالي للمستودع

### ✅ المرحلة 0+1 مكتملة: التأسيس + نواة المحاسبة (بوابة G1)

النظام يعمل فعلياً الآن: خادم FastAPI + قاعدة SQLAlchemy (SQLite محلي / PostgreSQL
إنتاج) + واجهة React عربية RTL — مع **20 اختباراً آلياً ناجحاً** يثبت القواعد الحمراء:

| القاعدة الحمراء (ملف 02 من الدراسة) | التطبيق |
|---|---|
| مدين = دائن إلزاماً | تحقق V1 + فحص الصفريّة الصافي في الميزان |
| لا تعديل/حذف لمرحَّل — عكس فقط | لا توجد نقاط PUT/PATCH/DELETE أصلاً (مختبَر 405) |
| ترقيم تسلسلي مقفل بلا ثغرات | عدّاد لكل نوع/سنة مؤمَّن صفّياً (`JV-MA-2026-000001`) |
| Idempotency | Outbox + `event_key` فريد — إعادة الحدث آمنة |
| سجل تدقيق كامل مقاوم للتلاعب | سلسلة تجزئة SHA-256 + كاشف عبث `/api/audit/verify` |
| RBAC + أمان | 6 أدوار، Argon2id، JWT بدوران عائلي وكشف سرقة، قفل 5 محاولات |

**تشغيل سريع:**
```bash
cd backend && pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
# الواجهة: ابنِ frontend (npm ci && npm run build) وستُقدَّم تلقائياً على :8000
# دخول تجريبي: admin / admin123!Change
# بوابة G1: زر «تشغيل الشهر الفندقي التجريبي» في لوحة القيادة ← 132 قيداً متوازناً
```
الاختبارات: `cd backend && python3 -m pytest` (20/20 ✅)
الحالة التفصيلية: [`docs/STATUS.md`](docs/STATUS.md) · القرارات المعمارية: [`docs/DECISIONS.md`](docs/DECISIONS.md)

## 🔐 المبادئ غير القابلة للتفاوض

1. مدين = دائن دائماً — بلا استثناء. 2. لا تعديل ولا حذف لمرحَّل (عكس موثق فقط).
3. سجل تدقيق مقاوم للتلاعب لكل حدث. 4. الترخيص شرط تشغيل بإيقاف «رحيم» يحفظ
حق العميل في بياناته. 5. أقل امتياز لكل مستخدم. 6. لا نقل بلا تشفير ولا سر بلا
محفظة مفاتيح. 7. النسخ الاحتياطي الآلي شرط تشغيل لا ميزة. 8. جودة الإصدار الأول
بمعيار Enterprise — لا منطق MVP في ما يمس المال والقيود.
