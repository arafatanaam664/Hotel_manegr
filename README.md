# نظام أثير — نظام ERP محاسبي إداري متكامل لإدارة الفنادق

**Atheer Hospitality ERP** — نظام محاسبي إداري من الدرجة المؤسسية (Enterprise‑Grade)
لإدارة الفنادق، يعمل بثلاثة أوضاع من قاعدة كود واحدة:

- **محلي (On‑Premise):** يعمل 100% بدون إنترنت داخل الفندق.
- **سحابي (SaaS):** متعدد المستأجرين بنسخ وتحديثات مركزية.
- **هجين (Hybrid):** تشغيل محلي كامل + مزامنة آمنة مع السحابة (لاحقاً).

> **القاعدة الجوهرية:** كل عملية مالية = قيد محاسبي مزدوج متوازن عبر محرك القيود
> فقط (مدين = دائن دائماً). القيد المرحَّل لا يُعدَّل ولا يُحذف أبداً — التصحيح
> بقيد عكسي موثق. وكل حدث مُدوَّن في سجل تدقيق متسلسل التجزئة مقاوم للتلاعب.

## 🚀 التشغيل السريع (دقائق)

### المتطلبات (مرة واحدة)
| الأداة | الإصدار | موقع التنزيل |
|---|---|---|
| Python | 3.11+ | https://www.python.org/downloads/ |
| Node.js | 20+ | https://nodejs.org |

### الخطوات

**على ويندوز:** انقر نقراً مزدوجاً على `scripts\run.bat`
(أو من سطر الأوامر: `scripts\run.bat`)

**على لينكس / ماك / Git‑Bash:**
```bash
bash scripts/run.sh
```

السكربت يجهّز كل شيء تلقائياً (بيئة معزولة + الحزم + بناء الواجهة) ثم يشغّل
النظام. عند ظهور «النظام يعمل الآن» افتح المتصفح على:

### 👉 http://localhost:8000

**الدخول التجريبي:** المستخدم `admin` — كلمة المرور `admin123!Change`

> قاعدة البيانات (SQLite) تُنشأ وتُملأ ببيانات فندق تجريبية عند أول إقلاع —
> لا يلزم أي إعداد. لإعادة البدء من الصفر: احذف الملف `backend/atheer_dev.db`
> وشغّل من جديد.

### تشغيل يدوي (للمطورين)
```bash
python3 -m venv .venv && source .venv/bin/activate   # ويندوز: .venv\Scripts\activate
pip install -r backend/requirements.txt
cd frontend && npm install && npm run build && cd ..
cd backend && uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### Docker (تشغيل إنتاجي مرجعي مع PostgreSQL)
```bash
echo "DB_PASSWORD=ضع-كلمة-سر-قوية" > .env
echo "JWT_SECRET=$(openssl rand -hex 32)" >> .env
docker compose up --build
```
ثم افتح http://localhost:8000 (بدون بيانات تجريبية — `SEED_ON_STARTUP=false`).

### الاختبارات الآلية (240 اختبارًا)
```bash
cd backend && python3 -m pytest
```

عطل شائع: «المنفذ 8000 مستخدم» ⇐ أوقف النسخة الأخرى أو غيّر المنفذ:
`cd backend && uvicorn app.main:app --port 8080`

## 🗺️ خريطة الجولة — المراحل المنجزة حتى الآن (بوابات G1..G10 + وحدة الغرف والأسعار والأجنحة)

كل بند في القائمة الجانبية (بعد تسجيل الدخول) يقابل مرحلة مكتملة ومختبَرة:

### 🟢 G1 — نواة المحاسبة (الأساس لكل شيء)
- **لوحة القيادة:** مؤشرات حية (مقبوضات اليوم، إشغال، مبيعات منافذ، قيود).
- **دليل الحسابات:** الشجرة الفندقية كاملة (أصول/التزامات/إيرادات/مصروفات).
- **القيود اليومية + قيد يدوي جديد:** كل قيد يتحقق V1..V8 قبل الترحيل الذري.
- **ميزان المراجعة + دفتر الأستاذ:** دليل صحّة المحاسبة اللحظي.
- **سجل التدقيق:** كل حدث بسلسلة تجزئة — زر «فحص السلامة» يكشف أي عبث.

### 🟢 G2 — العمليات الفندقية
- **مكتب الاستقبال:** براك الغرف اللوني (نظيفة/مشغولة/وسخة/خارج الخدمة) —
  تسكين ≤ 60 ثانية، Walk‑in، نقل غرفة، مغادرة بفاتورة.
- **الحجوزات:** إنشاء بفحص توفر لحظي + حالات كاملة (تأكيد/وصول/إقامة/مغادرة/إلغاء).
- **النزلاء والشركات:** ملفات نزلاء بهوية مشفّرة + شركات بحدود ائتمان.
- **تجربة:** احجز غرفة ← سكّنها ← شاهد الفوليو يتولّد لحظياً من الدفتر.

### 🟢 G3 — التدقيق الليلي
- **التدقيق الليلي:** ترحيل آلي لبدلات الغرف (حدث #3) + إقفال اليوم + تقدّم
  تاريخ الأعمال + لقطة إشغال/ADR/RevPAR — ذرّي ومُقفل بعد الإثبات.

### 🟢 G4 — نقاط البيع POS
- **شاشة البيع:** لمسية RTL باختصارات (F2 تسديد، F9 إلغاء) + دعم باركود +
  تعمل أوفلاين (طابور مزامنة تلقائي).
- **الطلبات والفواتير + الورديات و Z:** إلغاءات بمشرف وسبب، Z أرشيفي موقّع.
- **كتالوج البيع + تقارير البيع:** أصناف مركّبة بوصفات تخصم مكوّناتها آلياً.
- **تجربة:** بِع «برجر لحم» نقداً ← شاهد مخزون المكوّنات ينقص في تقارير المخزون.

### 🟢 G5 — المخزون والمشتريات
- **كتالوج المخزون:** أصناف بوحدات بديلة إلزامية المعامل، مستودعات بحسابات
  مالية مستقلة، موردون بأسعار تعاقدية مؤرخة.
- **دورة المشتريات:** طلب ⇐ أمر شراء (سِلّم اعتماد حسب القيمة) ⇐ استلام GRN
  (مرحَّل لا يُعدَّل أبداً — عكس فقط) ⇐ **مطابقة ثلاثية PO↔GRN↔فاتورة** توقف
  أي فرق سعر آلياً ⇐ سداد بخصم مكتسب ⇐ مرتجع بمستند مستقل.
- **حركة المخزون:** صرف للأقسام، تحويلات باستلام مزدوج، هالك باعتماد،
  **جرد دوري بتجميد النطاق + اعتماد مزدوج** ⇐ تسويات #19/#20 بالهِلّلة.
- **تقارير المخزون:** مطابقة يومية «قيمة المخزون = الأستاذ» + تنبيهات إعادة
  طلب/صلاحية (30‑15‑7)/راكد + استهلاك نظري مقابل فعلي (كاشف الهدر والتلاعب).
- **تجربة:** أنشئ أمر شراء واعتمد استلامه ← افتح تقارير البيع والمخزون وشاهد
  القيد #15 والمتوسط المرجَّح المتحرك ينعكسان فوراً.

### 🟢 G6 — الموارد البشرية والرواتب
- **شؤون الموظفين:** ملفات بعدسات خصوصية (راتبك لا تراه بنفسك، وقسم الإدارة
  🔒 لا يُكشف بلا تفويض)، أقسام بمراكز تكلفة وحسابات GL، خطابات تغيير بمستند
  واعتماد غير ذاتي.
- **الوقت والحضور:** رصد جماعي → اعتماد المشرف (غير المعتمد لا يُحتسب أبداً)،
  ورديات وجداول Roster، إجازات بأرصدة واستحقاق شهري، جزاءات تأديبية بمستند.
- **الرواتب والمسيرات:** معالج شهري بأربع حالات (مسودة ← HR يجهّز ← **المالية
  تعتمد — وذات-الاعتماد ممنوع** ← ترحيل #21 ← صرف #22) + سلف بجدولة إقساط
  آلية (#23) + قسائم وأرشيف وبنود وسياسة قابلة للضبط لأي بلد.
- **تقارير التوظيف:** كشف شهري قسم/موظف/بند، مقارنة أشهر، تقادم السلف، أرصدة
  الإجازات، الدوران، وكلفة الموظف مقابل إيراد الشهر (مؤشر USALI بحدّ 40%).
- **تجربة:** أنشئ مسير الشهر كـ«HR» ثم جرّب اعتماده بنفسك ⇐ يُرفض بصراحة؛
  أنشئ مستخدم مالية من إدارة المستخدمين واعتمد به ← شاهد قيد #21 متوازناً
  موزعاً على أقسامك في القيود اليومية.

### 🟢 G7 — الأصول الثابتة + إقفال السنة + القوائم المالية
- **الأصول الثابتة 🏭:** سجل بتكلفة/خردة/عمر (قسط ثابت أو متناقص بأرضية
  الخردة) + تشغيلة إهلاك شهرية #24 مرة واحدة فقط + جدولة استشرافية + علم
  «السجل ≡ الأستاذ».
- **القوائم المالية 🧾:** قائمة دخل USALI قسمية (غرف/مأكولات ← GOP ← صافٍ)،
  ميزانية متوازنة بقطع، تدفقات نقدية بهوية Δ نقدية المقفلة، أعمار ذمم
  FIFO تطابق الأستاذ حرفياً.
- **الإقفال والفترات 🔐:** خريطة 12 فترة (لين ← صلب لمامَس)، ثم معالج
  إقفال سنة بقائمة تحقق حية: قيد إقفال واحد متوازن (الصفرية للإيراد
  والمصروف والربح إلى الأرباح المبقاة) ⇒ سنة جديدة بـ12 فترة ⇒ افتتاحية
  آلية بأرصدة كل طرف (نزيل/شركة/مورد/موظف) — كل ذلك ذرّياً أو لا شيء.
- **تجربة:** شغّل إهلاك الشهر من شاشة الأصول ⇐ شاهد قيد #24 في اليومية؛
  أغلق أشهر السنة ليناً ثم افتح معالج الإقفال وراقب شروطه تخضرّ.

### 🟢 G8 — الترخيص (صارم على الترخيص، رحيم بالتشغيل)
- **ملفات .license موقعة Ed25519:** التحقق محلي 100% بلا إنترنت؛ تعديل حرف
  واحد = رفض فوري. المفتاح الخاص لا يغادر يد الشركة (`license_tool`).
- **دورة حياة رحيمة:** مهلة تجديد بكامل الوظائف ← وضع قراءة فقط (تقاريرك
  وتصديرك وطباعتك سليمة دائماً — بياناتك حقك المطلق) ← لا إيقاف نهائي إلا
  بوثيقة موقعة من الشركة.
- **بصمة جهاز متسامحة 2/3:** استبدل قطعة واحدة بلا إزعاج؛ انقل النظام
  لجهاز آخر فيُكتشف. تفعيل معزول تماماً بملف طلب بصمة.
- **حماية من عبث الساعة:** رجوع الساعة أكثر من يوم = قفل احترازي بلا فقدان
  أي بيانات، يفكّه ملف إصلاح من الشركة.
- **حدود الباقة حية:** الوحدات وعدد المستخدمين والفروع مقفلة برسائل ترقية
  واضحة — جرّبها من شاشة 🔑 حالة الترخيص في القائمة الجانبية.
- **تجربة:** افتح «حالة الترخيص» ← شاهد الترخيص الساري والبصمة 3/3
  والحدود ⇐ لو انتهت المهلة سترى الشريط الأحمر لكن كل تقاريرك تبقى تعمل.

### 🟢 G9 — لوحة تحكم الشركة المالكة (تطبيق مستقل، منفذ 8100)
- **قلب الإيرادات:** عملاء واشتراكات خطط بسقوف خصم، فواتير بتذكير
  30/14/7، تحصيل موثّق ← **سداد التجديد يوقّع ترخيصاً جديداً آلياً يصل
  العميل فوراً** عبر واجهة العميل المحدودة /edge.
- **MRR دقيق حسابياً:** لوحة إيراد (MRR/ARR/تجديد/Churn/أعمار تأخر/متوقع
  90 يوماً) بإثبات تفصيلي — لا انحراف هللة واحدة.
- **تراخيص باعتماد ثنائي:** تجاوز حدود الخطة يوقّف الإصدار حتى يعتمد مدير
  ثانٍ؛ قوائم إلغاء موقعة؛ علم فوري لو ظهرت بصمة جهاز على عميل آخر.
- **دعم بضبط عسكري:** أولويات P1–P4 بـSLA محسوب، P1 يُشعِر المناوب خلال
  ثوانٍ، سير عمل كامل، سبب جذري إلزامي لإغلاق أي عطل، تصعيد حتى هندسة
  المنتج.
- **MFA إلزامي بلا استثناء** لكل فريق الشركة + أقل امتياز + تدقيق مستقل.
- **تشغيل المعاينة:** `bash scripts/run_vendor.sh` ثم http://localhost:8100
  — الدخول: `director / vendor123!Change` ورمز TOTP يطبعه
  `backend/scripts/vendor_totp.py` (بيئة تطوير فقط).

### 🟢 G10 — محرك المزامنة الهجينة (محلي ⇄ سحابي ⇄ هجينة)
- **«مركز المزامنة» 🔄:** حالة حية (معلق/مرسل/مؤكد/فجوات)، زر «دفع فوري»
  يوصل الحدث المالي خلال ثانية، «رفع أولي» يلحق كل بيانات ما قبل المزامنة،
  وضع توفير للشبكات الضعيفة، سحب تراخيص من المورّد، نبضة صحة، وتصدير
  USB مشفر وموقَّع للفنادق شديدة العزلة.
- **صارم بنيوياً:** كل حدث موقَّع Ed25519، Inbox فريد = إعادة الإرسال
  آمنة دائماً، فجوة تسلسل تُكتشف فوراً وتُستدرك آلياً، تعارض الماسترات
  لا يُحسم صامتاً — صندوق تعارض بعرض جنباً إلى جنب وقرار بشري موثق.
- **اختبار الفوضى الإلزامي ×1000** (قطع شبكة/طاقة/فقدان حزم عشوائي):
  صفر فقدان، صفر ازدواج، فجوات ≤1، وميزان مراجعة السحابة = ميزان المحل.
- **تشغيل عقدة سحابة:** نفس الكود بيئة مستقبِل — انظر `scripts/run_cloud.sh`
  ثم التبويب 🔄 بالموقع المحلي: «اقتران» ← «رفع أولي» ← «دفع فوري».

### 🟢 G10.5 — الغرف والأسعار والأجنحة المركبة
- **شاشة 🛏 الغرف والأسعار (خمسة تبويبات):** الغرف (إضافة/تعديل بربط جناح
  وفكّه وتعطيل محروس)، أنواع الغرف بأسعار ليلتها الأساسية، خطط الأسعار
  (مرجع إضافي فوق الأساس + إفطار/سياسة/أدنى ليالٍ)، تقويم الأسعار (تعبئة
  موسم/مناسبة حتى 92 يوماً بلا تكرار)، والخدمات الإضافية بحساب إيرادها.
- **تسلسل التسعير الحي:** سعر الليلة = تقويم اليوم ⇐ خطة الحجز ⇐ أساس
  النوع — والليلة المنقضية تحتفظ بسعرها (لقطة لا تتغير أبداً).
- **الأجنحة المركبة 🏰 (كما تعمل الفنادق فعلاً):** جناح يُباع كاملاً
  بسعره الخاص ⇐ يقفل غرفه الداخلية تلقائياً؛ وغرفة منه تُباع منفردة ⇐
  يُقفل الجناح وحده وتبقى أخواتها تُباع. الصيانة OOO تحجب الاتجاهين،
  وإلغاء الحجز يحرر الجميع فوراً.
- **تجربة:** افتح 🛏 ⇐ تعرّف الجناح الملكي J-401 (= غرفتا 401 و402) ⇐
  احجز J-401 كاملاً من شاشة الحجوزات ⇐ براك الاستقبال يقفل 401 و402
  بشارة 🔒؛ ألغِ الحجز فتتحرر الثلاثة لحظياً.

## ✅ ما يضمن الصحّة (240 اختبارًا آلياً — `pytest`)

| القاعدة الحمراء | الإثبات الآلي |
|---|---|
| مدين = دائن إلزاماً، ترحيل ذري، تسلسل مقفل بلا ثغرات | مختبَر V1..V8 |
| المرحَّل لا يُعدَّل/يُحذف (قيود + GRN) — عكس فقط | 405/409/404 من كل المسارات |
| ممنوع رصيد مخزون سالب — حتى تحت التزامن الخيطي | اختبار تزامن ينجح فيه واحد فقط |
| قيمة المخزون أي يوم = رصيد حسابه في الأستاذ | تقرير مطابقة + فحص ليلي آلي |
| المطابقة الثلاثية ترفض فرق السعر/الكمية خارج التسامح | توقف تلقائي VARIANCE_HOLD مختبَر |
| لا حجز مزدوج / إعادة إرسال آمنة (Idempotency) | Outbox + أحداث فريدة + اختبارات |
| الجناح وغرفه لا يُباعان مرتين: حجب مشتق بالاتجاهين + فك ربط محروس | حارس موحد على 5 مداخل مختبَر |
| فصل المهام: لا اعتماد ذاتي (أوامر/فواتير/جرد/سلف/مسيرات) | 403 في الاختبارات والواجهة |
| صافي مسير #21 = رصيد 2310 وموزَّع على أقسامه | عينة ذهبية موقَّعة بالهللة مختبَرة |
| استحالة خصم سلفة فوق رصيدها أو راتب لموظف منتهٍ | حُرّاس خدمة مختبَرون |
| راتبك لا تراه بنفسك؛ القسيمة بلا صلاحية = 403 ومشاهدتها مُدقَّقة | خصوصية صفية مختبَرة |
| تشغيلة إهلاك = مرة واحدة لكل شهر، والقسط بالهللة وأرضية الخردة | أرقام ذهبية + RUN_EXISTS |
| الإقفال يصفِّر الإيراد/المصروف والصافي → 3201 والافتتاحية بأطرافها | قبول-7/2·7/3 موقَّع |
| التقارير لا تضاعف الأرصدة عند عبور السنة (مرساة الافتتاح) | ميزان 2027: 3201=7000 مرة واحدة |
| هوية النقدية: تشغيلي+استثماري+تمويلي ≡ Δ النقدية | فارق صفر مختبَر |
| مجموع دلاء الأعمار ≡ رصيد حساب الأستاذ | 1110/1120/2101 مختبَرة |
