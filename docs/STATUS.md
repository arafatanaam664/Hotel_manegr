## كيفية التشغيل

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
# الدخول التجريبي: admin / admin123!Change  (بيئة تطوير فقط)
```
الاختبارات: `cd backend && python3 -m pytest`

## ملاحظة تشغيلية — CI
ملف GitHub Actions جاهز في `.github-ready/workflows/ci.yml` ولكن **غير مفعَّل**:
توكن GitHub App للجلسة لا يملك صلاحية `workflows` فيرفض الخادم رفع أي ملف داخل
`.github/workflows/`. التفعيل يدوياً من واجهة GitHub (نسخ الملف) أو بصلاحية أوسع.
