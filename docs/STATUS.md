## الواجهة الأمامية ✅ (محدّثة بالفندق + POS + المخزون)
استقبال براك لوني لحظي، حجوزات (إنشاء بفحص توفر + Walk-in)، ملف حجز كامل،
تدقيق ليلي، نزلاء وشركات — يضاف الآن: شاشة بيع لمسية RTL كاملة بطابور أوفلاين،
لوحة طلبات وشاشة تحضير KDS، ورديات وتقارير Z، كتالوج ووصفات ومخزون،
تقارير مبيعات بالأبعاد الستة + مؤشرات الرقابة — ومع G5: كتالوج مخزون
(أصناف/تصنيفات/مستودعات/موردون وأسعار تعاقدية)، دورة مشتريات كاملة
(طلبات/أوامر/استلامات/فواتير بمطابقة ثلاثية/سداد ومرتجعات)، حركة مخزون
(صرف/تحويلات باستلام مزدوج/هالك/جرد بتجميد وشبكة عدّ واعتماد مزدوج)،
وتقارير المخزون والتنبيهات والسياسة القابلة للضبط.
