# 08 — كتالوج الإشعارات (Notification Catalog)

> **المرحلة الثانية — تصميم فقط.** كل بنود هذا الملف 🆕 (لا يوجد محرك إشعارات اليوم — الفجوة G-23).
> المعمار: ENG-NFY — حدث → قاعدة (DLG-NTF-001) → شرط → جمهور (دور/أشخاص) → قنوات → أولوية → طابور Idempotent (مفتاح=الحدث، لا تكرار) → سجل تسليم + إعادة إرسال يدوية وتلقائية (Backoff: 1د/5د/30د؛ 5 فشل=صف ميت بمراجعة).

## 1. القنوات — الجاهزية المرحلية (قرار واقع السوق)
| القناة | المرحلة | الوسيلة | ملاحظة يمنية/عالمية |
|---|---|---|---|
| **In-App** (صندوق SCR-NTF-001) | **P1** | داخلي | القناة الافتراضية دائماً، تعمل بلا إنترنت |
| **Email** | **P1** | SMTP قابل للضبط بالجهة | رسمي: كشوف/تقارير مجدولة/تراخيص |
| **SMS** | P2 | بوابة مزود (محلي: عدن نت/spaace…، عالمي: Twilio-class) | تأكيدات حجوزات قصيرة |
| **WhatsApp Business** | **P2** | واجهة Meta الرسمية عبر مزود معتمد | **القناة الجماهيرية الأولى يمنياً** للنزيل |
| Push (متصفح) | P3 | Web Push API | يعمل والنظام مغلق نسبياً |
| Desktop | P4 | مع أداة مكتبية لاحقاً | غير أولوي |

## 3. قواعد حاكمة للتصميم
1. **لا إغراق:** تجميع ذكي لحدود المخزون اليومية؛ قابل للضبط لكل قاعدة (فوري/مجمّع ساعي/يومي).
2. **ساعات هدوء** لقنوات النزيل (23:00–07:00 افتراضياً) قابلة للضبط بإعدادات الجهة.
3. **قوالب عربية أولاً** بمتغيرات موثقة؛ نسخة إنجليزية مع i18n (P3)؛ معاينة القالب داخل DLG-NTF-001 قبل الحفظ.
4. **إلغاء الاشتراك القانوني** لقنوات النزيل (رابط/رد) مسجل بملفه.
5. **سجل تسليم** موحد يظهر بمركز الإشعارات (نجاح/فشل/سبب/إعادات) — ويتغذى بتقرير RPT-ADM-006 لاحقاً.
6. العدّ: **36 حدثاً مؤتلفاً** (8 فندق + 2 نزيل + 6 مالية + 4 مخزون + 3 موارد + 3 أمن + 6 نظام + 4 شركة)، القنوات 6، والتجربة الأولى P1 بقناتي In-App+Email فقط.
