## SET-TAX الضرائب — شاشة جديدة SCR-SET-006 (**P1** — يملأ فراغاً معمارياً مؤكداً: جداول الضرائب بلا API حالياً!)
ضريبة: اسم/نوع (إضافية/مدرجة)/نسبة/حساب تحصيل/سريان/إعفاءات بالبنود — كل تعديل بدليل وأثر رجعي ممنوع (Recompute يبدأ من تاريخ القرار).
## SET-PRM الصلاحيات/الأدوار ✅
أدوار مدمجة+مخصصة/استثناءات/نوافذ — الجديد 🆕: قوالب أدوار جاهزة للفنادق (فندق 30غ/منتجع/شقق) في WIZ-001.
## SET-LNG اللغات (P3)
عربي أساس (افتراضي)؛ إنجليزي لاحقاً؛ تعيين لغة كل مستخدم (U) ولغة مستندات العميل (T).
## SET-CUR العملات — شاشة جديدة ضمن SCR-SET-006 (**P1**)
عملة أساس واحدة T + عملات تعامل: رمز/كسور عشرية/رمز عرض؛ أسعار الصرف بدليل وتاريخ نفاذ وسياسة إعادة التقييم (تلقائي شهري؟).
## SET-BRN الفروع (T→B)
إنشاء/تعطيل فرع، توريث الإعدادات، مخزون/سلاسل خاصة بكل فرع ✅ جزئياً — WIZ-004 يجعلها رحلة موجهة.

## العدّ الرسمي
- **أسطح الإعداد الحالية: 16** (موثقة بتدقيق المرحلة الأولى) — تُعرض كلها بالمركز الموحد.
- **شاشات إعداد جديدة: 6** (SET-001…006) + **إعدادات فردية جديدة: ≈ 32** موثقة أعلاه بالمراحل.
- قاعدة قبول: لا إعداد بقيمة افتراضية صامتة — كل افتراض معلن في الواجهة وفي هذا الكتالوج.
