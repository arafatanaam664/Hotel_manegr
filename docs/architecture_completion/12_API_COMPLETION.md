## D. عقد الـ API الملزم لكل جديد («قانون الكتابة»)
1. مسار: `/api/v1/{module}/{resource}` جمعاً، أفعالٌ `POST …/{action}`؛ أخطاء: `{error:{code:'MOD.REASON', message_ar, details?}}` بسجل أكواد مركزي.
2. RBAC مُصرَّح لكل نقطة في جدول كتالوج 10؛ لا «داخلي مفتوح».
3. Idempotency: POST المالية تقبل `Idempotency-Key` + event_key دوميني إلزامي.
4. Pagination/فرز/فلترة معيارية (`page,size≤200,sort,q,from,to,status`)؛ استجابة `{items,total,page,size}`.
5. UTC دائماً؛ مبالغ Numeric(19,4) نصوصاً في JSON؛ هويات لا تُعاد إلا مقنّعة.
6. تدقيق: كل كتابة تسجل actor/before/after؛ تصدير ملف يُسجل كحدث.
7. توثيق: Schema بأمثلة + أكواد أخطاء لكل مسار منشورة OpenAPI.
