# 04 — كتالوج معالجات الخطوات (Wizard Inventory)

> **المرحلة الثانية — تصميم فقط.** ✅ موجود | 🆕 مصمَّم هنا.
> قالب التوثيق لكل معالج: الخطوات • شرط الانتقال (Gate) • شرط الفشل • التراجع • الإلغاء • الحالة النهائية المقفلة.
> مبدأ معماري ملزم: كل معالج **قابل للاستئناف** (يحفظ تقدمه)، وكل خطوة لها **نتيجة موقعة**، والإلغاء لا يترك نصف أثر (كل خطوة ذرية).

## WIZ-001 — معالج الإعداد الأول للنظام 🆕 (P1) — شاشة المضيف: تُشغَّل تلقائياً لأول تشغيل
| العنصر | التفصيل |
|---|---|
| الخطوات (7) | 1) بيانات الجهة والفرع الأول والعملة والمنطقة الزمنية ← 2) دليل الحسابات (افتراضي USALI معتمد vs استيراد) ← 3) خريطة الربط المحاسبي (اعتماد افتراضي/تخصيص) ← 4) السنة المالية وفتراتها ← 5) الغرف والأنواع وخطط الأسعار (استيراد XLSX أو إدخال سريع) ← 6) المستخدمون والأدوار ← 7) تثبيت الترخيص والمزامنة (اقتران) |
| شرط الانتقال | اكتمال التحققات لكل خطوة (مثلاً 2: شجرة متوازنة الأرقام؛ 3: كل حدث الـ27 له حساب) |
| شرط الفشل | أي تحقق أحمر يمنع التالي؛ يعرض تقرير جاهزية مفصلاً |
| التراجع | حر إلى أي خطوة سابقة قبل الختم؛ البيانات محفوظة كمسودة إعداد |
| الإلغاء | يُبقي الحالة «إعداد غير مكتمل» وتُقفل الوحدات التشغيلية حتى الاكتمال |
| الختم | إصدار «محضر تهيئة» موقّع بالمنفذ + تدقيق؛ يفتح العمل ويقفل المعالج نهائياً |

## WIZ-002 — التدقيق الليلي ✅ (مرقّى رسمياً كمعالج) — المضيف SCR-HTL-013 — صلاحية nightaudit.run
| العنصر | التفصيل |
|---|---|
| الخطوات (7 — ملف 03 §4) | 1) وصولات اليوم: كل CONFIRMED حضر أو No-Show ← 2) مغادرات اليوم: خرجوا أو مدّدوا ← 3) ترحيل ليالٍ الإقامة (ذرّي، event_key فريد = استحالة تكرار ليلة) ← 4) ترحيل شحنات مجدولة يومية 🆕 (باقات/رسوم ثابتة — الفجوة الباقية من النص) ← 5) فحوص الجولة: أرصدة صناديق×نظام، فواتير شاذة (إقامة طويلة بلا دفع)، OOO متعارض مع حجوزات ← 6) عدّاد High Balance للفوليوهات فوق الحد ← 7) إقفال اليوم: Business Date جديد + **لقطة تقرير يومية موقعة غير قابلة للتعديل** + دفع للسحابة |
| شرط الانتقال | كل خطوة تعرض عناصر معلقة ويجب تسويتها أو تعليلها موثقاً |
| شرط الفشل | فشل ترحيل ليلة = دحرجة كاملة للخطوة 3 (كل الليالٍ أو لا شيء) ✅ |
| التراجع | لا تراجع عن «إقفال اليوم» — البديل الرسمي: إعادة فتح يوم بصلاحية مزدوجة (مدير+مالي) ومسوغ وسجل ✅ |
| الإلغاء | قبل الإقفال: تقدم محفوظ قابل للاستئناف بنفس اليوم التجاري فقط |

## WIZ-003 — إقفال السنة المالية 🆕 (P1) — المضيف SCR-ACC-008 — periods.close
| العنصر | التفصيل |
|---|---|
| الخطوات (6) | 1) فحوص قبل الإقفال (موجود API close-precheck ✅): قيود مسودة/فواتير معلقة/فترات مفتوحة ← 2) قيود التسوية الافتتاحية والإهلاكات المتبقية ← 3) تقرير مُراجَع: ميزان+دخل نهائي موقع من المدير المالي ← 4) قيد الإقفال (إقفال أرباح على حساب الأرباح المبقاة) ← 5) قيد افتتاح السنة الجديدة بأرصدة AF/BF آلية ← 6) ختم: السنة CLOSED نهائياً + أرشفة لقطة |
| شرط الانتقال | موافقة دورين (مالي ثم مالك) على الخطوة 3 |
| شرط الفشل | أي حساب غير متوازن طرفي (1110/1120/2101) بذمة بلا مستند |
| التراجع | قبل الختم فقط؛ بعد الإقفال التصحيح = قيد افتتاحي عكسي بصلاحية مزدوجة |
| الإلغاء | آمن — لا أثر دفتري قبل خطوة 4 |

## WIZ-004 — فتح فرع/فندق جديد 🆕 (P2) — settings.manage
| العنصر | التفصيل |
|---|---|
| الخطوات (5) | 1) هوية الفرع (رمز/اسم/عنوان/منطقة زمنية) ← 2) نسخ قوالب: غرف/أنواع/خطط من فرع مرجعي ← 3) أرصدة افتتاحية للفرع (مخزون/صناديق) ← 4) مستخدمو الفرق أووراثة أدوار ← 5) اقتران مزامنة مستقل للموقع الجديد |
| شرط الفشل | تداخل رموز الغرف مع الفرع الأب عند النسخ = تقرير تضارب |
| التراجع/الإلغاء | قبل التفعيل؛ الفرع غير المفعّل لا يظهر بالعمليات |

## WIZ-005 — استيراد وترحيل البيانات الافتتاحية 🆕 (P1) — المضيف SCR-ADM-006 — data.import 🆕
| العنصر | التفصيل |
|---|---|
| الخطوات (5) | 1) اختيار حزمة (نزلاء/موردون/أصناف/أرصدة افتتاحية/موظفون) ← 2) تنزيل قالب XLSX رسمي ← 3) رفع الملف + فحص آلي (أعمدة/أنواع/تكرارات/مراجع) ← 4) معاينة الخلل: سطور مقبولة/مرفوضة بأسباب ← 5) تنفيذ ذرّي لكل حزمة + تقرير نتيجة موقّع |
| شرط الفشل | أخطاء جوهرية>0 → السطور المعيبة تُستبعد والباقي يُستورد (لا تلويث) |
| التراجع/الإلغاء | قبل التنفيذ حر؛ بعده التصحيح بدفعة عكسية موثقة بمعرّف الاستيراد |

## WIZ-006 — إعداد قناة حجز/OTA 🆕 (P3) — settings.manage
| العنصر | التفصيل |
|---|---|
| الخطوات (4) | 1) اختيار القناة/المزود ← 2) بيانات الاعتماد (مفاتيح مشفرة ساكناً) ← 3) ربط الأنواع والخطط وتحديد مخزون مخصص (Allotment) ← 4) تجربة حجز وهمي E2E + تفعيل |
| شرط الفشل | فشل التجربة يمنع التفعيل |
| الإلغاء | تعطيل القناة يوقف الاستقبال ويُبقي الحجوزات القائمة |

## WIZ-007 — إعداد النسخ الاحتياطي 🆕 (**P0**) — المضيف SCR-MON-002 — backup.run 🆕
| العنصر | التفصيل |
|---|---|
| الخطوات (4) | 1) الوجهات: محلي + خارجي (USB/شبكة/S3 متوافق) ← 2) الجدولة (يومي موقّت/احتفاظ 3 أجيال أسبوعي/شهري) ← 3) تشفير النسخة بمفتاح مُدار ← 4) **اختبار استعادة إلزامي أول** (تستعيد لمجلد فحص وتتحقق من hash وفتح القاعدة) |
