## 1. الفندق

### WFL-HTL-01 دورة حياة الحجز ✅
- **الحالات:** TENTATIVE → CONFIRMED → CHECKED_IN → CHECKED_OUT · أفرع نهائية: CANCELLED / NO_SHOW.
- **الانتقالات:** إنشاء= TENTATIVE (reservations.create، فحص توفر+قفل تفاؤلي) · تأكيد=اختياري بعربون حدث #01 · تسكين=CHECKED_IN (checkin.do؛ غرفة Clean افتراضياً أو checkin.dirty_override) · مغادرة=CHECKED_OUT (checkout.do بعد فحوص WFL-HTL-04) · إلغاء=CANCELLED (reservations.cancel + سبب إلزامي + غرامة حدث #02) · No-Show=اقتراح آلي مساء ليلة الوصول، تنفيذ يدوي (حدث #03).
- **اعتمادات:** استثناء غرفة غير نظيفة؛ غرامة خارج السياسة؛ إلغاء بلا غرامة لحجز مؤكد بعربون.
- **استثناءات موثقة:** يوم عمل خارج النافذة HOTEL.OUTSIDE_WINDOW (لا تسكين يوم المغادرة) ✅؛ تمديد يفحص توفر ويُنبّه فرق سعر ✅.

### WFL-HTL-02 Walk-in بخطوة واحدة ✅
إنشاء+تسكين في معاملة واحدة (مصدر WALKIN) → نفس ضمانات التسكين؛ القبول الزمني ≤60ث لا يُكسر.

### WFL-HTL-03 تسجيل الوصول ✅
هوية/مرافقون (مشفرة) → تخصيص غرفة → تطبيق العربون #07 → بطاقة تسجيل 🆕. فشل الهوية لحامل حجز ملزم قانونياً = تحذير أحمر لا منع (المعلومية تحذيراتها P0 توثقه).

### WFL-HTL-04 تسجيل المغادرة ✅
فحوص **مرتبة إلزامية**: (1) شحنات معلقة/ميني بار 🆕 ← (2) رصيد صفر: تحصيل #07 أو ترحيل شركة #08 بصلاحية checkout.credit_transfer وحد ائتمان ← (3) رسوم مغادرة متأخرة #4103 إن طُبقت 🆕 ← إقفال فوليو → غرفة Dirty → فاتورة ضريبية متسلسلة تُطبع ✅. إعادة فتح فاتورة: **ممنوع** — التصحيح بإشعار دائن+قيد عكسي ✅.

### WFL-HTL-05 نقل غرفة ✅
إنهاء شريحة إقامة+فتح أخرى بنفس الفوليو (reservations.modify بسبب)؛ القديمة Dirty آلياً؛ سجل شرائح كامل يغذي سجل الغرفة SCR-HTL-011.

### WFL-HTL-06 التدقيق الليلي ✅ — انظر WIZ-002 (7 خطوات ببوابات).

### WFL-HTL-07 الخصم فوق الحد ✅
طلب folio.discount فوق حد الدور → حالة PENDING_APPROVAL → اعتماد discounts.approve (مدير) أو رفض بمسوغ → عند الاعتماد يقيّد حدث #06 ويظهر بتقرير RPT-HTL-013. 🆕 إشعار لحظي للمدير عبر ENG-NFY.

### WFL-HTL-08 مجموعات وفوليو رئيسي 🆕 P2
إنشاء Block (منسق/تواريخ/تقطيع أنواع) → توزيع غرف → إقامات فرعية → إقفال جماعي: فرعيات مسواة أو محولة للرئيسي (#08 جماعي) → فاتورة رئيسية مجمعة + إيصالات فرعية. اعتماد: نسبة Block فوق السقف بقرار GM.

### WFL-HTL-09 قائمة الانتظار 🆕 P2
طلب بلا توفر → WAITLISTED (بأولوية/مصدر) → عند تحرر نوع مناسب: إشعار ترقية للاستقبال → قبول يرقّي لـTENTATIVE مع سعر محفوظ أو رفض بسبب → انقضاء تلقائي بعد تاريخ الوصول +إشعار.

### WFL-HTL-10 المعلومية اليومية ✅
بناء نطاق «كل من لامس الفندق» → معاينة+تحذيرات → توليد XLSX رسمي → أرشيف موقّع sha256 → إعادة تنزيل دائمة. لا انتقال حالة يدوي (غير قابل للتوهيم).
