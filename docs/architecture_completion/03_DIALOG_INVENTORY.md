# 03 — كتالوج النوافذ المنبثقة (Dialog Inventory)

> **المرحلة الثانية — تصميم فقط.** التاريخ: 2026-08-07.
> ✅ موجود · 🟡 موجود اليوم كنموذج مضمّن بالصفحة ويُحوَّل لنافذة نمطية موحدة · 🆕 جديد.
> لكل نافذة: سبب الظهور، الحقول، التحقق، الصلاحية، الأخطاء المرقمة (كود مرجعي للدعم)، السيناريوهات.
> معيار عام ملزم لكل النوافذ: إغلاق بـEsc مع تحذير فقدان إن وُجد إدخال • Enter=تأكيد إن كانت صالحة • تركيز أول حقل • منع نقر مزدوج • Idempotency بمفتاح حدث • رسائل خطأ عربية معيارية `ERR.XXX.NNN`.
