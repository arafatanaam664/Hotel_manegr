# 01 — الخارطة النهائية للنظام (Final Enterprise System Map)

> **المرحلة الثانية — تصميم فقط (لا كود).** التاريخ: 2026-08-07 | الحالة: مرجع رسمي ملزم لكل مراحل التطوير القادمة.
> الحالات: ✅ موجود يعمل v0.14.0 | 🟡 موجود جزئياً/ناقص طبقة | 🆕 مصمَّم هنا لأول مرة (جديد كلياً)
> المعرفات: SCR=شاشة، DLG=نافذة، WIZ=معالج، RPT=تقرير، DSH=لوحة معلومات، SET=إعداد — تفاصيلها في كتالوجاتها.

## طريقة القراءة
النظام = **4 طبقات**: (أ) نواة المنصة (محركات لا شاشات لها)، (ب) وحدات الأعمال، (ج) الطبقة العرضية المشتركة (تقارير/إشعارات/ملفات/بحث/مساعدة/مراقبة)، (د) لوحة الشركة + الواجهات العامة الخارجية.

---

## (أ) نواة المنصة — Platform Core (لا تظهر للمستخدم مباشرة)

```
PLT نواة المنصة
├─ ENG-ACC محرك المحاسبة ✅ (خريطة 27 حدثاً، قيود متوازنة، عكس، عزل فترات)
├─ ENG-IAM هوية وأمن 🟡 (جلسات/قفل/نوافذ دوام/RBAC ✅ — MFA فندقي 🆕، سياسات كلمات 🆕)
├─ ENG-LIC ترخيص 🟡 (توقيع/بصمة/حالات/إبطال ✅ — إدارة أجهزة متعددة 🆕)
├─ ENG-SYN مزامنة هجينة 🟡 (محرك كامل ✅ — التغطية 3 كيانات، توسعة السجل 🆕)
├─ ENG-AUD تدقيق وأحداث ✅ (سلسلة موقعة، idempotency بمفاتيح أحداث)
├─ ENG-NUM تسلسلات رقمية رسمية ✅
├─ ENG-NFY محرك إشعارات 🆕 (قواعد/قنوات/طابور/إعادة إرسال — كتالوج 08)
├─ ENG-FIL مخزن ملفات 🆕 (مرفقات/صور/مستندات — محلي أولاً، تخزين كائني اختياري)
├─ ENG-PRT طباعة وتصدير 🆕 (PDF عربي + XLSX + CSV موحد، قوالب، توجيه طابعات)
├─ ENG-SCH مجدول مهام 🆕 (نسخ/تذكيرات/تقارير مجدولة/إهلاك تلقائي)
├─ ENG-BKP نسخ واستعادة 🆕 (محلي+خارجي، اختبار استعادة، RPO/RPO معلن)
├─ ENG-ARC أرشفة وتنقية 🆕 (سياسات احتفاظ لكل جدول، نقل لأرشيف بارد)
└─ ENG-SRH فهرسة بحث 🆕 (بحث شامل عبر الكيانات)
```
